# 视觉设计记录

概念：`concept.png`，内置 Image Gen 生成。独立生产插画：`../assets/coast.png`，从概念参考生成；没有裁切整张 UI 当作产品界面。

设计系统：沙色 #f5f2e9；墨青 #193e43；棋盘 #729190；浅色面板 #dce5dd；宋体中文、Georgia 数字；12px 棋盘间隙，7–19px 圆角。桌面使用左侧标题与海岸插画、右侧完整棋盘。移动端优先棋盘，隐藏装饰插画并收紧标题。

刻意采用原生代码界面的内容：棋盘、数字、评分、按钮、波浪 SVG 图标；这是数字解谜界面，不需要角色精灵或物理碰撞贴图。

概念提示词：完整中文桌面海岸主题 2048 游戏，1536×1024，浅沙背景与深青文字，左侧“潮汐 / 2048”“把喧嚣留在岸上。滑动、相遇，合成你的 2048。”及俯瞰海湾插画，右侧两个分数区域、4×4 青绿色棋盘、撤销一步 / 新的一局 / 音效按钮；顶部潮汐与玩法，底部“不赶时间，慢慢来。”和来源链接。清晰留白、可实现的原生控件，不增加无关面板。

生产插画提示词：仅提取概念左下海岸插画并生成完整 3:2 独立素材；细腻绘画纹理，左侧奶油色沙滩、右侧青绿色海水、岩石白色浪花、左下深绿植被，右上海面一艘小橙色帆船；保持原配色和自然光，无 UI、文字、数字、边框，圆角交由代码实现。
