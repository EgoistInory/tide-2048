# 潮汐 2048

中文海岸主题数字合成游戏。原生 HTML、CSS、JavaScript，无构建步骤，无第三方运行时依赖。

## 运行

直接用浏览器打开 `index.html` 即可玩。为获得稳定的浏览器存档，也可在本目录执行：

```sh
python3 -m http.server 4188 --bind 127.0.0.1
```

访问 http://127.0.0.1:4188 。服务只监听本机，不会自动向公网发布。

## 操作

- 方向键 / WASD，或在棋盘上滑动；鼠标拖动也支持。
- 相同数字合并；每次有效移动随机出现 2（90%）或 4（10%）。
- 合成 2048 获胜，可继续挑战；填满且无法合并才结束。
- 撤销最近一次有效移动；无效移动不消耗撤销机会。
- 新局确认后重新开始，保留最高纪录。音效默认关闭。
- 当前进度、一次撤销、最高纪录、音效开关自动保存在当前浏览器。隐私模式或存储被禁用时会显示提示，仍可游玩。不同浏览器和不同网址的存档不互通。

## 验证

```sh
node --test tests/engine.test.js
node --check app.js
```

浏览器验收与设计对照见 `docs/VERIFICATION.md`。可访问 `/tests/scenarios.html` 复验获胜、失败和存档异常；测试用隔离内存存档，不影响真实游戏进度。

## 文件

- `engine.js`：纯规则、滑动识别、存档校验；供浏览器和 Node 测试共同使用。
- `app.js`：界面、动画、输入、音效、对话框。
- `styles.css`：响应式设计及减少动态效果支持。
- `assets/coast.png`：生成的海岸插画；`assets/wave.svg`：界面波浪图标。
- `docs/concept.png`：视觉参考。`AGENT_PROGRESS.md`：可接续进度与验收目标。
